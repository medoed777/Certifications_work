# Electronics Network Management

## Описание

Это приложение предназначено для управления сетью по продаже электроники. Оно позволяет 
управлять поставщиками и сетевыми узлами, а также отслеживать задолженности перед поставщиками.

## Функциональность

- Управление поставщиками (добавление, редактирование, удаление).
- Управление сетевыми узлами (добавление, редактирование, удаление).
- Отображение задолженности перед поставщиками.
- Возможность очистки задолженности через админ-панель.
- RESTful API для взаимодействия с данными.

## Стэк
- Python 3.8+
- Django 3+
- DRF 3.10+
- PostgreSQL 10+

## Установка

1. Клонируйте репозиторий:
> git clone https://github.com/medoed777/Certifications_work.git

> cd Certifications_work
2. Создайте и активируйте виртуальное окружение:
> python -m venv venv

> source venv/bin/activate  # Для Windows используйте: venv\Scripts\activate

3. Установите зависимости:
> pip install -r requirements.txt
 
4. Примените миграции:
>python manage.py migrate

5. Запустите сервер:
> python manage.py runserver

Теперь вы можете открыть приложение по адресу [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin) 
для доступа к админ-панели и [http://127.0.0.1:8000/api/](http://127.0.0.1:8000/api/) для доступа к API.

## Использование API

### Поставщики

- **GET /api/suppliers/** - Получить список всех поставщиков.
- **POST /api/suppliers/** - Создать нового поставщика.
- **GET /api/suppliers/{id}/** - Получить информацию о конкретном поставщике.
- **PUT /api/suppliers/{id}/** - Обновить информацию о конкретном поставщике.
- **DELETE /api/suppliers/{id}/** - Удалить конкретного поставщика.

### Сетевые узлы

- **GET /api/network-nodes/** - Получить список всех сетевых узлов.
- **POST /api/network-nodes/** - Создать новый сетевой узел.
- **GET /api/network-nodes/{id}/** - Получить информацию о конкретном сетевом узле.
- **PUT /api/network-nodes/{id}/** - Обновить информацию о конкретном сетевом узле.
- **DELETE /api/network-nodes/{id}/** - Удалить конкретный сетевой узел.
